Support for {BRAND_NAME} runs through GitHub and this documentation.

## File an issue

Bug reports and feature requests belong on the [GitHub issue tracker](https://github.com/Hydra-Host/Brokkr/issues). For provisioning problems, include the platform version, the zone topology, and the lifecycle job timeline from the deployment's detail page.

## Report a security issue

Do not open a public issue for a vulnerability. Use [GitHub private vulnerability reporting](https://github.com/Hydra-Host/Brokkr/security) so the report stays private while a fix is prepared. The full policy is in [SECURITY.md](https://github.com/Hydra-Host/Brokkr/blob/master/SECURITY.md).

## Improve the documentation

Every docs page has an **Edit on GitHub** link in the right column that opens the page source. Corrections and clarifications are welcome as pull requests.

The [glossary](/help/glossary) defines every term the docs use, one meaning per term.
