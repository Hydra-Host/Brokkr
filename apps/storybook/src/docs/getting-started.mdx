# Getting Started

`@repo/ui` is the shared Hydra design system: a source-style component library built on
Tailwind CSS v4, [Base UI](https://base-ui.com), `class-variance-authority`, and the brokkr
theme system. Apps consume it directly as TypeScript source through package subpath exports —
there is no build step.

## Installation

Add the workspace dependency plus the Tailwind toolchain to your app:

```jsonc
// package.json
{
  "dependencies": {
    "@repo/ui": "workspace:*",
    "tailwindcss": "^4.1.18",
    "@tailwindcss/vite": "^4.1.18",
  },
  "devDependencies": {
    "tw-animate-css": "^1.4.0",
  },
}
```

Register the Tailwind Vite plugin:

```ts
// vite.config.ts
import tailwindcss from '@tailwindcss/vite';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

Wire the stylesheet — this is the complete CSS entry used by every Hydra app:

```css
/* src/index.css */
@import 'tailwindcss';
@import 'tw-animate-css';
@import '@repo/ui/styles/brokkr.css';
@source '../node_modules/@repo/ui';
```

The `@source` line makes Tailwind scan the library's own class names; the path is relative
to the CSS file and points at your app's `node_modules/@repo/ui` symlink. Fonts (Inter and
JetBrains Mono) load automatically through `brokkr.css`.

## Theme setup

Wrap your app in the `ThemeProvider`. It applies the `data-style`/`data-color`/`data-mode`
attributes to `<html>`, persists the choice to `localStorage`, and follows the OS light/dark
preference in `system` mode:

```tsx
import { ThemeProvider } from '@repo/ui/theme-provider';
import { configureUiBrand } from '@repo/ui/lib/brand';

configureUiBrand({ name: 'Hydra Commerce' });

<ThemeProvider>
  <App />
</ThemeProvider>;
```

See the [Theming guide](?path=/docs/guides-theming--docs) for the full list of themes and
design tokens.

## Optional peer dependencies

Two component groups need extra peers in the consuming app:

- **`react-hook-form` ^7** — everything under `@repo/ui/form/*` takes a `control` prop
  from `useForm()`.
- **`@tanstack/react-router` ^1** — `ButtonLink`, `useFilters`, and
  `useNavigationShortcuts` need router context.

Everything else works with just `react` and `react-dom`.
