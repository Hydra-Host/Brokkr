# Theming

The design system ships nine themes defined in `@repo/ui/styles/brokkr.css`. Every theme is a
`[data-theme='…']` block of CSS custom properties that overrides the base `@theme` tokens, and
`ThemeProvider` decides which value lands on `<html data-theme="…">`.

## ThemeProvider

`ThemeProvider` (`@repo/ui/theme-provider`) owns the `data-theme` attribute on `<html>` and
persists three localStorage keys:

- `brokkr-theme` — the current mode: a theme value or `system`.
- `brokkr-preferred-dark` — which dark theme `system` mode resolves to.
- `brokkr-preferred-light` — which light theme `system` mode resolves to.

Calling `setTheme('green')` selects that theme directly and also records it as the preferred
dark theme (likewise a light theme updates the preferred light). Calling `setSystemMode()`
switches to `system`, which follows the OS `prefers-color-scheme` and picks the preferred
dark or light theme accordingly — live, via a media-query listener.

`ThemeSelector` (`@repo/ui/theme-selector`) is the ready-made dropdown over this context; in
this Storybook the toolbar theme control drives the same provider.

## What the commerce themes change

`commerce-light` and `commerce-dark` restyle the terminal aesthetic into a payment-product
look. Beyond colors they:

- switch `--font-mono` from JetBrains Mono to **Inter**, so the whole UI renders in a
  proportional face;
- set real border radii (`--radius-sm` through `--radius-3xl`, which are all `0` in the
  terminal themes);
- hide the terminal corner-tick decorations on cards, inputs, tabs, and selects, replacing
  them with plain rounded borders.

## Forcing a theme on a subtree

Because every theme block uses a bare `[data-theme='…']` selector, a nested element with a
`data-theme` attribute re-scopes all custom properties for its subtree — no provider needed.
Apps use this for hosted pages that must ignore the visitor's saved theme:

```tsx
<div data-theme="commerce-light" className="bg-bg-primary text-text-primary">
  {/* everything in here renders in commerce-light */}
</div>
```

The [Themes gallery](?path=/story/foundations-themes--gallery) story uses exactly this
technique to render all nine themes side by side.
