# @repo/cli-core

Public CLI toolkit: small, framework-free helpers for building one-shot CLI
commands — output/`--json` rendering, pagination, config/session paths,
`@clack/prompts` wrappers, and a spinner. Used by `apps/cli` (Brokkr CLI) and
by `@hydrahost/admin-cli`.

## Open-core boundary

This package is public and Apache-2.0 licensed, and ships to the public GitHub
mirror. It must stay free of any dependency on proprietary packages
(`@hydrahost/*`) so it can be synced without redaction.
